# JDBC Problem Statements

## 1. Employee Management System

Add/list/search/update/delete employees; department salary report; unique email validation.

## 2. Student Attendance Tracker

Register students; mark attendance once per date; list daily attendance; calculate attendance percentages; identify students below 75%.

## 3. Personal Expense Tracker

Add expenses; list records; monthly total; category-wise totals; filter by month.

## 4. Library Book Issue and Return System

Add books and members; list books; issue a book only when available; return an active loan; calculate overdue fine at ₹10/day.

## 5. Inventory and Stock Manager

Add products; receive stock; record sale; list inventory; low-stock alerts; transactionally record movement and stock quantity.

## 6. Mini E-Commerce Order System

Create an order with one item; lock and check stock; decrement inventory; save order and item in one transaction; cancel an order and restore stock.

## 7. Bank Account Transfer Simulator

Create account; view balances; transfer funds atomically; reject same-account, non-positive, and insufficient-balance transfers; record transfer history.

## 8. User Registration and Login

Register with unique email; login using a salted PBKDF2 password hash; change password; never store plaintext passwords.

## 9. Employee Payroll Generator

Add employees; generate payroll for a month; calculate net salary; prevent duplicate payroll per employee/month; view monthly payslips and department totals.

## 10. Customer Complaint Tracker

Register customers; create complaints; assign priority; update status; list open complaints; view complaint history by customer.
